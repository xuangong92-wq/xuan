## 交付前需你完成的三件事

1. **替换占位姓名**：全局把 `XXX` 改为**答辩人姓名**、`XXX 教授` 改为**导师姓名**；如需，可调整"学科专业 / 培养单位 / 答辩日期"。
2. **插入论文原图**：正文页均设有虚线"**图表占位区**"，框内注明了对应的论文图号与建议内容（如 `Fig.2`、`Fig.5 A–D`）。直接把论文图片拖入相应占位框即可；插入后可删除占位说明文字。
3. **加入武汉大学校徽（可选）**：封面与内容页右上留有校名文字位，可叠放官方校徽图片；PPT 未内置校徽以避免使用非官方素材。

> 提示：字体默认使用 **微软雅黑（Microsoft YaHei）**，Windows + 中文 Office 可直接正常显示；如在 Mac 演示，建议提前安装该字体或改用系统等宽中文字体。

## 二次修改

如需增删页面或改文字，可直接编辑 PowerPoint；也可修改 `build_deck.js` 后重新生成：

```bash

```
